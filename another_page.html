About This Page

CSS stands for Cascading Style Sheets. It is used to control the appearance of a web page, including colors, fonts, spacing, backgrounds, and layout.

Using External CSS

An external stylesheet allows multiple HTML pages to share the same design. When you change the styles.css file, the appearance of both pages can change automatically.
